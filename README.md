# 🐷 Porco-cliquer-V1

Um jogo no estilo **Clicker** super divertido desenvolvido para a plataforma Android. O objetivo principal é clicar no porquinho para acumular pontos e evoluir no jogo!

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias nativas:
* **Kotlin** (Linguagem de programação principal)
* **Android Jetpack** / XML (Para a interface do usuário)
* **CMake & C++** (Para integrações nativas de performance)

## 🛠️ Como rodar o projeto

Para abrir e testar este projeto no seu computador:
1. Faça o download ou clone este repositório.
2. Abra o **Android Studio**.
3. Selecione a opção **Open an Existing Project** e escolha esta pasta.
4. Aguarde a sincronização do Gradle e clique em **Run** para rodar no seu emulador ou celular.
